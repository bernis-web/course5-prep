# 04 模板规范

## 必须保留的模板元素（每一页都有）

| 元素 | 位置 | 说明 |
|---|---|---|
| 顶栏蓝条 | 0 → 9.56″ 宽，y=0.72″ | 深蓝渐变，不许缩短 |
| 顶栏金条 | 10.19″ 起，宽 3.14″，y=0.72″ | 金色 `#FFC000` |
| 校徽 | 右上 10.63″, 0.09″，1.92×0.59″ | 不许缩放、不许挪 |
| 底部浅金条 | y=6.45″，高 0.44″，全宽 | 底色 `#FFF2CC` |
| 结论句 | 底部条上，13pt 粗体 `#8A4B00` | **每页都要写一句**，一句话结论 |
| 页码 | 右下 11.6″, 7.06″，8.5pt | 02–10 |

## 字号阶梯（只有四档，别自己加）

| 用途 | 字号 | 颜色 |
|---|---|---|
| 页面标题 | 24pt 粗体 | `#12365A` |
| 副标题 | 12.5pt | `#60758F` |
| 正文 | 11–13pt | `#1F2D3D` |
| 结论句 | 13pt 粗体 | `#8A4B00` |
| 数字大字（少用） | 30–38pt 粗体 | `#12365A` |
| 页脚/来源 | 8.5–10pt | `#60758F` |

## 配色（只用这五个）

| 名称 | 值 | 用途 |
|---|---|---|
| 深蓝 | `#12365A` | 标题、数据主色 |
| 中蓝 | `#4A7FA5` | 图表第二系列 |
| 浅蓝灰 | `#8FA9BC` | 图表第三系列 |
| 金 | `#FFC000` | 强调、最高值 |
| 浅金底 | `#FFF2CC` | 底部结论条 |

**不许用红色**。要表达"错的"用深蓝 + 删除线，或者灰色。

## 图表规范

- 只许横向条形图（`BAR_CLUSTERED`），不许饼图、3D、雷达图
- 不要网格线；坐标轴只留类别轴一条细线
- 数据标签：9pt，放在柱子末端外侧
- 图例：放图表顶部，10.5pt
- 每个图表都要有单位说明（如「macro-F1，越大越好」）
