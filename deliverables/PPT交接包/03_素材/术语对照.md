# 术语对照（被问到就查）

| 术语 | 人话 |
|---|---|
| 单细胞测序（scRNA） | 把组织拆成一个个细胞，逐个读它表达了哪些基因 |
| coarse / fine 标签 | 粗类（9–10 类，如"心肌"）/ 细类（如"心室肌"） |
| 1:1 同源基因 | 两个物种里能一一对上的基因 |
| macro-F1 | 每个类各算 F1 再等权平均，不被大类绑架 |
| union 口径 | 真实 ∪ 预测一起参与平均，预测出真值里没有的类记 0 分 |
| strict_cell | 保留全部细胞，对不上的预测算错（本汇报统一用这个） |
| n_q | 进入分母的细胞数 |
| transductive / in-sample | 评估时数据里已包含待预测细胞（不是留出评估） |
| 多数类基线 | 全场都猜最多的那一类，作为"无信息"对照 |
| iLISI / kBET / silhouette | 三个批次混合指标（本汇报不展开） |
