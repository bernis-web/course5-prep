# 课题5 第三次汇报 · PPT 制作交接包

> 给做 PPT 的同学：这个包里是你需要的一切。**你不需要懂单细胞分析**，照着做就行。

## 任务

| 项 | 要求 |
|---|---|
| 交付格式 | `.pptx`，16:9（13.33 × 7.5 英寸） |
| 页数 | **10 页**（已定死，不要增减；如需调整先问） |
| 时长 | 约 10 分钟（约每页 1 分钟；P04/P06 可给 1.5 分钟） |
| 模板 | **必须用学校模板**（`04_模板规范.md`） |
| 字体 | 微软雅黑（中英文都用它） |
| 文件命名 | `课题5_第三次汇报_<你的名字>_2026111X.pptx` |

## 你手上有什么

- `01_大纲.md`：10 页骨架，先看一眼
- `02_逐页brief.md`：**逐页写清放什么、放哪、用什么图** ← 主要照这个做
- `03_素材/数据源.xlsx`：所有数字，按页分好了 sheet，可直接插图表
- `03_素材/`：三张参考渲染图（**只看结构，不抄视觉**）
- `04_模板规范.md`：模板元素与安全区
- `05_验收清单.md`：交之前自己过一遍

## 三条铁律

1. **数字一个字都不许改**。数据源 xlsx 里是什么就是什么；看着不顺眼也不许四舍五入。
2. **只讲结论，不讲实现**。方法公式、代码、参数一律不上页。
3. **不要写花了多少钱**。这一页已经被删掉，别再捡回来。

## 你不需要做的事

- 不用跑任何分析、不用看原始数据
- 不用理解 SATURN/SAMap 的原理细节（brief 里给的比喻够用）
- 不用改模板配色和版式结构
- 不用做动画/切换效果
