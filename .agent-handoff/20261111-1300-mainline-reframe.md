### 🔴 供体级 cluster bootstrap 完成（2026-11-11 15:25）—— 发现此前 CI 系统性过窄

**脚本**：`scripts/donor_bootstrap.py`
**输出**：`results/bootstrap-donor-20261111/donor_bootstrap.{json,md}`

**为什么做**：我们此前所有 CI 都是**逐细胞**重抽样。同一供体/样本里的细胞并不独立，

### ⏱️ KMeans 耗时的量化估算 + 未来优化（2026-11-11 17:34，第 42 轮）

#### 复杂度估算（为什么这个耗时是合理的）

`KMeans(n_clusters=2000).fit(embeds)`，其中 `embeds` ≈ 24000 × 1280：

| 项 | 值 |
|---|---|
| 每个 E-step 的距离计算 | `(24000×1280) @ (1280×2000)` ≈ **6.1e10 MAC** |
| 单核 BLAS 约 2–5 GFLOPs | 每步 **约 15–30 秒** |
| 收敛所需迭代 | k=2000 时约 **50–100 步** |
| sklearn ≥1.2 的 `n_init='auto'` | `init='k-means++'` 时 **= 1**（不是老版的 10） |

→ 合计 **约 15–50 分钟**。**所以现在 24 分钟属正常，预计不久会完成。**

#### 未来优化（写给消融阶段用）

`make_centroids` 里的 KMeans **没有设 `n_jobs`** → 单线程。
**给消融阶段的建议**：把该行改成

```python
kmeans_obj = KMeans(n_clusters=num_centroids, random_state=seed, n_jobs=-1).fit(embeds)
```

**为什么安全**：`random_state` 固定时，`n_jobs` **只并行化计算，不改变聚类结果**。
（sklearn 的 KMeans 用 OpenMP 线程并行，与随机状态无关。）

**配合更大的 CPU 档**（如 32c128g）→ 这一步可从几十分钟压到几分钟。

**这条同时也解释了平台选择**：我们现在用 2c8g，如果这一步是瓶颈，
**「投更大的 CPU 档」比「等更久」更划算**——因为它是纯计算密集型，且能并行。

### 🔴🔴 新发现：我们的 oPCA 是 transductive 的（2026-11-11 20:50，第 75 轮）

**源码证据**：`scripts/ortholog_pca_dcs_v3_fixkey.py:278-282`

```python
        X_joint = np.vstack([Xs, Xt]).astype(np.float64)      # ← 源 + 目标一起堆
        ...
        Z = PCA(n_components=NPCS, random_state=SEED).fit_transform(X_joint)
```

**→ PCA 在「源物种 + 目标物种」细胞上联合拟合 → 拟合时已看到目标细胞
→ 我们的 oPCA 是 transductive 的，不是 inductive。**

**这正是 Claude 咨询第 5 条**（「现有全部是 transductive，应补 held-out」）所指的问题。

**为什么重要**：真实部署时**拿不到目标物种细胞**。transductive 拟合会泄漏目标分布信息，
**可能系统性抬高分数**，并让我们的数与 inductive 方法**不可直接比**。

#### 实测：改成 inductive 后分数变了多少

**脚本**：`scripts/transductive_ablation.py`
**输出**：`results/transductive-20261111/transductive_vs_inductive.{json,md}`
**改法**（最小改动）：`PCA(...).fit(Xs)` 只用源细胞拟合，再 `transform(X_joint)`

| 方向 | transductive acc | **inductive acc** | Δ |
|---|---|---|---|
| 人→鼠 | 0.8618 | 0.8186 | −0.0432 |
| **鼠→人** | 0.7369 | **0.5144** | **−0.2225** |
| 人→斑马鱼 | 0.1811 | 0.2056 | **+0.0245** |
| **斑马鱼→人** | 0.2788 | **0.0949** | **−0.1839** |
| 鼠→斑马鱼 | 0.2730 | 0.2566 | −0.0164 |
| 斑马鱼→鼠 | 0.5967 | **0.6625** | **+0.0658** |

**Δ 范围 −0.2225 ~ +0.0658，均值 ≈ −0.0626。**

**三条结论**：
1. **影响量级很大**（最大 −0.22），**远大于一般方法间差距**；
2. **但方向不单调**——两向显著下降（鼠→人 −0.2225、斑马鱼→人 −0.1839），
   **两向反而上升**（人→斑马鱼 +0.0245、斑马鱼→鼠 +0.0658）。
   → 所以**不是「transductive 一律抬高」**，而是**它对不同方向影响不同**；
3. **两条大幅下降的都是「→human」方向**（鼠→人、斑马鱼→人）——**值得单独追**。

**⚠️ 连带影响（必须处理）**：
- 所有此前基于 transductive oPCA 的**配对结论**都可能改变
  （尤其 `鼠→人`：transductive 0.7369 → inductive **0.5144**，掉了 0.22）；
