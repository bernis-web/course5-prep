## 6 踩过的坑（下次别再踩）

1. **`git add -A` 会把 90 MB × 6 的 wheelhouse 分卷提交进去**（它们已被跟踪，gitignore 无效）。
   我犯过一次，用 `git reset --soft HEAD~1` + `git restore --staged wheelhouse` 撤销了。
2. **`git` 命令不能并行跑**，会撞出 `index.lock`，表现为「Another git process seems to be running」。
   等几秒它们自己退出，锁会自动释放，**不要手删锁**。
3. **`pdftoppm *.pdf` 在 PowerShell 里不展开通配符**，必须传 `(Get-ChildItem *.pdf)[0].FullName`。
4. **不存在的 API key 会让 web_search 直接失败**，github 搜索改用 `gh` 或 `Invoke-RestMethod raw.githubusercontent.com`（API 有速率限制，raw 没有）。
5. **子代理的会话会污染 `resume.mjs` 的候选池**，判据是 `rows.subagent.val.identity` 存在（不是 `val` 存在）。
6. 这个仓库**有别的会话在同时提交**（`.gitignore` 被改、暂存区被重置、提交数自己涨过）。
   动 git 前先 `git status` 看一眼，别假设状态是你上次留下的。
7. **验收证据图会「过时」**：`render/v2/gray|thumb|_contact` 是子代理从 `_candidate2.pptx`
   渲的，而定稿文件后来又去了期次、改了封面冒号 —— 证据图里页脚还带着已删的字。
   改完 pptx 一定重跑 `scripts\rebuild_deck_evidence.py` 从定稿重生成，否则给队友看的
   样张和交付物对不上。
