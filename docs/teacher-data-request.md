# 启动课题5前的 DCS 只读查询清单

老师已确认数据和工具信息可以在 DCS 查询。下面 6 项先由组员在学术搜索、数据记录和镜像页面只读核实；只有实在找不到的项目再集中询问，不需要先消耗云资源：

已取得的公共检索键：HEART 为 DOI `10.1126/science.adw0855` / CNGB `CNP0006537`，LBSPA 为 DOI `10.1126/science.aea2535` / CNGB `CNP0007565`。当前 DCS 项目公共库按题名简称和两个 accession 搜索均未命中，因此以下清单关注的是课程挂载证据，而不是重复查论文元数据。

1. HEART 16 物种数据的 DCS 挂载路径和实际文件格式（`.h5ad`、`.rds` 或矩阵目录）。
2. HEART 的物种字段、细胞类型字段、批次字段和论文金标准标签字段名称。
3. 可用物种清单，以及如何从中选择首轮 2–3 个物种；后续需能构造近缘、远缘和不同类别混合组合。
4. LBSPA 七鳃鳗与小鼠的 snRNA 数据路径；空间数据已明确不纳入主实验，单核数据只在单细胞结论后小规模测试。
5. 推荐使用 `SATURN--22`、`samap_all` 或其他课程专用镜像；每个镜像的 SATURN/SAMap/scVI 版本是否已锁定。
6. 正式 kBET 的实现和版本要求，以及是否允许把 scANVI、Harmony、LIGER 作为扩展对照。

建议查询时记录一个只读示例目录和一行命令，能打印对象的细胞数、基因数和元数据字段，不需要复制或上传原始数据。页面仍找不到时，再请课程管理员补充这一项。
