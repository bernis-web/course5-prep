# 启动课题5前向课程管理员确认

请一次性确认下面 6 项，拿到答案后即可开始第一轮，不需要先消耗云资源：

1. HEART 16 物种数据的 DCS 挂载路径和实际文件格式（`.h5ad`、`.rds` 或矩阵目录）。
2. HEART 的物种字段、细胞类型字段、批次字段和论文金标准标签字段名称。
3. 课程是否已经准备 3 物种/8 物种子集，还是需要从 16 物种对象自行抽取。
4. LBSPA 七鳃鳗与小鼠的 snRNA 数据路径；空间数据是否要求纳入第一轮。
5. 推荐使用 `SATURN--22`、`samap_all` 或其他课程专用镜像；每个镜像的 SATURN/SAMap/scVI 版本是否已锁定。
6. 正式 kBET 的实现和版本要求，以及是否允许把 scANVI、Harmony、LIGER 作为扩展对照。

建议课程管理员同时提供一个只读示例目录和一行命令，能打印对象的细胞数、基因数和元数据字段，不需要复制或上传原始数据。
