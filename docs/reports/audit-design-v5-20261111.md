# v5 汇报设计验收（2026-11-11）

## 目标

按目标书的三条硬指标逐页验收 v5 汇报：**留白 ≥ 25% / 对齐误差 ≤ 0.1" / 图优于字**，
不达标的当场改，改完重测。附带 CRAP 的另两条（对比、重复）与字号层级。

## 原理

三条指标都得先**把口径钉死**，否则数字随便就能自证「达标」：

| 指标 | 口径 | 为什么这么定 |
|---|---|---|
| 留白 | 渲染 110 dpi，与**页面主色**（众数像素）差异 ≤6 的像素占比 | 用白底阈值会把封面深蓝底算成 1.6% 墨（v1 的错） |
| 对齐 | 同页内容元素左缘按 0.06" 聚成列线，取**簇内极差**；卡片内文与卡片左缘偏移必须 = PAD(0.36)±0.02 | 把所有 left 拿去比「版心网格」会把卡片内部文本框也算成错位（v1 的错） |
| 对比 | 正文级（≤12pt）run 前景 vs **其所在形状填充色**（无填充退到页面主色），WCAG ≥ 4.5 | 一律对白底算会把深底白字算成 1.22（v1 的错） |
| 图优于字 | 承载定量信息处必须是图表；清单/定性页用文字正确 | 判的是「该用图的地方用了字」，不是「必须全图」 |

## 实现：本轮改了什么

**① 内边距与第二栏统一（18 处常量替换）**

`build_report_v5.py` 原来内边距混用 0.30 / 0.35 / 0.36，第二栏混用 `M+4.15 / M+4.35 / M+4.60`。
新增两个常量并全量替换：

```python
PAD  = 0.36   # 卡片内边距，全篇唯一值
COL2 = 4.60   # 第二栏起点（相对版心左缘）
```

`cx+0.30 ×6` / `M+0.30 ×3` / `M+0.35 ×1` / `M+0.36 ×4` → `…+PAD`；
`M+4.35 ×2` → `M+COL2`；`M+6.40 ×2` → `M+6.46`（贴合其宿主框 6.10+PAD）。

**② 第 7 页「变化要点」内文对齐**

原来写死 `9.10`，与宿主框 `8.80` 的偏移是 0.30 而非 0.36 → 改成 `8.80 + PAD`。

## 坑

1. **v1 体检脚本自己报了 10/10 不达标**，全是口径错：白底阈值、白底对比、全量网格对齐。
   先修测量再改版，顺序反了会白改一版。
2. `RECT` 的 `left` 与其中文本的 `left` 是两套坐标，替换 `+0.30` 时漏掉一种写法
   （写死 `9.10`）就会留一页 0.30 偏移。记分卡的 `PAD违例` 列就是防这个的。
3. 改内边距会推高文字占位，重建后必须重跑渲染 + 重测，不能只信 pptx 几何。
