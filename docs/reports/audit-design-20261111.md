## 0. 测量口径（先声明，避免数字被误读）

| 口径 | 定义 | 局限 |
|---|---|---|
| 几何 | python-pptx 直读 `left/top/width/height`，换算英寸，保留 4 位小数 | 不反映文本实际渲染高度 |
| 占用率 | 0.05 in 网格采样，形状外接矩形与版心求交 | **图表外接矩形被整体计为占用**，图内绘图区留白未被扣除；S04/S05/S07 的空白率因此被低估约 8–10 个百分点 |
| 空白率 | `1 − 占用率`，分「版心口径」与「整页口径」两列 | — |
| 字号档位 | 段落 run 字号去重计数 | 8.5pt 为模板页脚/页码，单独标注 |
| 行宽 | em 宽度：全角 1.0、半角 0.55、空格 0.5；只统计**单行放得下**的段落 | 换行后的实际行宽不测 |
| 对比度 | WCAG 2.1 相对亮度公式 | 只算文字/底色，不算投影 |
| 孤儿行 | 估算行数取末行字数 ≤25% 满行 | 3 处报警均为拉丁字符串宽度误报，人工复核后判定**无真实孤儿行** |
