## 本次汇报的目的

本次不新增实验数字，也不把候选结果升级成正式 benchmark。目标是把已有结果按“证据在哪里、能否复算、还缺什么”重新分层，并把阶段 1 已经完成的 A-smoke 与仍受平台调度影响的全量复算明确区分。

老师上一轮提出的核心问题是：表格里的百分比如何得到、为什么不同方法不能直接排名。本轮先冻结状态；下一轮再逐格展示一个百分比从原始 AnnData、表示层、标签、分母、预测文件到混淆矩阵的完整生成链。

## 一、状态分类与证据层级

### 五档状态

- **confirmed**：已有独立审计或双通道互证。
- **candidate-final**：通过阶段 Gate，但仍保留外部确认或协议限制。
- **exploratory**：初步运行或方法学对照，口径尚未冻结。
- **pending**：等待外部条件（平台、签认或文件回收）。
- **blocked**：存在已知阻塞，不能靠重复提交解决。

另有一个非互斥标签：**confirmed-for-recompute**。它表示某个隔离复算已经通过，可以作为后续复算的可信起点；它不等于三物种六方向全量 benchmark 已完成。

### 四个存在层级

1. **本地**：本地文件存在并可校验；
2. **容器/日志**：只在 DCS 容器或日志中确认；
3. **数字级**：有数字，但没有逐细胞文件；
4. **已复算**：本地独立重算并与冻结结果核对。

“容器级存在”不等于“本地文件已回收”，日志级数字也不等于文件级 provenance。

## 二、已有评估结果的当前口径

### 1. ortholog-PCA

六方向×三层的冻结结果保留为 candidate-final。coarse 六方向数字为：

`0.8618 / 0.7369 / 0.1961 / 0.2755 / 0.1813 / 0.5761`。

其主结果有本地 `metrics.json`、manifest 和逐细胞预测/混淆矩阵等文件级证据。它仍属于 transductive / in-sample 评估，不可直接解释为 inductive 泛化能力。

### 2. SAMap v98

六方向×三层结果保留为 candidate-final；coarse 的 human→mouse 为 `0.1050`，18 格结果均需与各自分母、coverage 和置换检验一起阅读。SAMap 合规重跑是方法学对照，当前结论是本规模下没有超过随机/多数类基线的跨物种对齐信号。

### 3. SATURN v99 与 v97g

- v99 统一评分器的 human→mouse coarse 为 `0.4844`。它有容器级 provenance 与回收锚点，但与 v97g 使用的标签空间不同，不能合并成一个排名。
- v97g 的 human→mouse coarse 为 `0.6179`，当前仍是**日志级数字**：没有逐细胞预测文件，因此不能把它写成文件级已复算结果。

两者都必须标注为 transductive / in-sample；SATURN 的训练标签通道与评估真值通道不能混写，机制措辞以源码审阅后的收窄表述为准。

### 4. 消融、ceiling 与 seed

- ESM2 消融 `67.4% → 20.4%` 是 v72-era 同协议配对的方向性结果；v97g 对应消融没有重跑。
- 物种内 ceiling `85.5 / 93.5 / 74.2` 按成对引用使用，不作为跨方法冠军证据。
- seed 稳定性 `67.1±3.8` 及鱼方向双峰结果只支持方向性判断，不能替代多 seed 的正式置信区间。
