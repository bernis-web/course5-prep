## 第 3 页 · 一个常见误解

**常见问法**：「四个方法，哪个最好？」

如果按六方向 macro-F1 求平均：

| 方法 | 六方向均值 |
|---|---|
| scVI | **0.4986** |
| SATURN | 0.4611 |
| ortholog-PCA | 0.3857 |
| SAMap | 0.0334（三个 n=0 方向按 0 计入；若只算有值的三个方向为 0.0668） |

看上去 scVI 第一。但这个排名**不成立**，因为四个方法的"分母、特征空间、训练方式、统计强度"都不同。

核心句：**把不同分母的分数平均，得到的不是排名，是加权错觉。**

## 第 4 页 · 边界一：分母

| 方法 | 每方向进入评估的细胞数 |
|---|---|
| ortholog-PCA | 1,499–1,528（≈100%） |
| scVI | 1,499–1,528（98–100%） |
| SATURN | 459–1,309（29–87%） |
| SAMap | 0–1,368（0–91%） |

SATURN 在 h→z 只用了 1,032 个细胞，SAMap 在三个方向 n=0。

**含义**：分母小的分数，方差更大；而 n=0 的方向根本无法比较。
正确做法：报分时必须同时报 n；跨方法比较只在**同一批细胞**上有意义。

## 第 5 页 · 边界二：特征空间

| 方法 | 输入空间 |
|---|---|
| scVI | 三物种共同 human 轴 **9,018** 基因 |
| ortholog-PCA | 每方向独立成对基因集：人鼠 15,869 / 人鱼 9,311 / 鼠鱼 8,160 |
| SATURN | ESM2 蛋白嵌入 + macrogene |
| SAMap | 同源图对齐（无固定基因数） |

**含义**：scVI 的 9,018 不是"更少信息"，而是"必须共享轴才能联合训练"的方法学约束；
oPCA 每方向独立 SVD，不需要共享轴，因此能保留物种特异信号。

正确写法：方法节分别交代两次特征空间定义，结论里声明"非同一数量，不做横向比较"。

## 第 6 页 · 边界三：训练方式

| 方法 | 训练粒度 | 是否见过 query |
|---|---|---|
| ortholog-PCA | **每方向独立** PCA-50 | 是（联合 PCA，transductive） |
| scVI | **一次训练、多方向评估** | 是（全部细胞参与训练） |
| SATURN | 一次训练、多方向 | 是 |
| SAMap | 一次对齐、多方向 | 是 |

- 四个方法**全部是 transductive**，没有一个是 held-out；
- 但 oPCA 的"每方向独立"与其余三个的"一次训练多方向"不同：
  前者对每个方向都重新拟合，后者共享一个嵌入。

**含义**：这不是公平与否的问题，是两种不同的评测设计，必须在报告里说明，
不能把"每方向独立"的方法和"共享嵌入"的方法放在同一句话里比高低。

## 第 7 页 · 边界四：统计强度

| 项 | 现状 |
|---|---|
| seed | 单 seed（0），无多种子重复 |
| 置信区间 | 无 |
| 置换检验 | 200 次，只回答"是否优于随机打乱" |
| 多重比较校正 | 无（18 格 × 4 方法） |

**两个常见误读**：

1. 把 `shuffle_p=0.04` 读成"该方法显著更好"——它只说明优于随机打乱，不说明优于多数类基线；
2. 把 0.05 的差距当实质差异——单 seed 下，这个量级不足以支撑结论。

## 第 8 页 · 正确读法

**不排总分，按场景选**：

| 场景 | 首选 | 依据 |
|---|---|---|
| 近缘（人↔鼠） | oPCA（scVI 接近） | 两者均值 0.658 / 0.629 |
| 远缘·人↔鱼 | scVI | 0.4014 vs SATURN 0.2479 |
| 远缘·鼠↔鱼 | SATURN | 0.6500 vs scVI 0.4248 |
| 跨门 | 不建议 | 两法均失败 |
| 无 GPU | oPCA | 30 秒；scVI 8.5 分钟 |

**四条边界语必须随数字出现**：
① 全部 transductive；② 分母不同；③ 特征空间不同；④ 单 seed。
