# pptx 图表缓存扫描（2026-11-11）

## 目标

补上一片盲区：`python-pptx` 读不到图表缓存，正文改对了、图里的数字仍可能是旧的。
本报告解全部 pptx 的 `ppt/charts/chart*.xml`，逐个比对作废值清单，判断哪些页必须重出。

## 原理

图表数据在 pptx 里存两份：`c:cat`/`c:val` 的结构化缓存，和 `embed` 的 xlsx 工作簿。
渲染器优先用缓存，所以**只改正文不改缓存，屏幕上还是旧数字**。
判定不能靠读源码，必须直接解 XML 里的 `<c:v>`。


## 坑

- 只扫 `<c:v>` 会漏掉分类轴（`c:cat` 里也是 `<c:v>`，是字符串不是数字），
  所以脚本只抓 `-?[0-9.]+` 形态，避免把方向名误判成数字。
- `chart*.xml` 的编号与幻灯片顺序**无关**，定位到页要看 `slideN.xml.rels` 里的 `chart` 关系，
  不能凭 chart1 = 第 1 页去猜。
- 旧版 pptx 用 `c:numCache` 而非 `c:numLit`，两者都是 `<c:v>`，正则通吃。
