# 汇报时长规范（2026-10-17 起生效）

> 用户要求（2026-10-17）：**以后的汇报做成 7–8 分钟的就可以，不用太长。**

## 硬性约束

| 项 | 规格 |
|---|---|
| **单次汇报时长** | **7–8 分钟**（口述） |
| 对应页数 | **6–8 页**（按每页约 1 分钟计） |
| 单页信息量 | 一个核心论点 + 至多 3 条支撑证据 |
| 禁止 | 单页塞入超过 5 条要点；连续 2 页以上纯文字 |

## 结构模板（7–8 分钟 / 6–8 页）

| 页 | 内容 | 时长 |
|---|---|---|
| 1 | 封面 + 本次要回答的一个问题 | 0.3 min |
| 2 | 结论先行（答案 + 关键数字） | 1 min |
| 3–5 | 支撑证据（每条一页，图/表为主） | 4 min |
| 6 | 限定与边界（transductive、分母、样本量） | 1 min |
| 7 | 需要决策/下一步 | 1 min |
| 8 | （可选）附录索引 | 0.3 min |

## 与旧规范的差异

旧做法（2026-10-08 至 10-15）：每册 7 页，但单页信息密度极高（表格 + 双卡片 + 底部结论条），
实际口述需 15–20 分钟。

**新规范**：页数不变或略减，但**大幅降低单页信息密度**——每页只讲一件事。

## 配套要求（不变）

- 任何数字必须从冻结 metrics 生成或逐格核对，禁止手工凭记忆改表
- 不把 transductive 写成 inductive
- 不把三方法按总分排"冠军"
- 限定语（分母、样本量、证据等级）必须随数字出现

## 适用范围

- 所有后续阶段汇报（第 11 次起）
- 已有汇报（1–10）不重做；若需重讲，按新规范压缩
- Word 终版报告不受此约束（报告可长，汇报要短）
