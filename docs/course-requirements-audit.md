# 课程要求核对

核对来源：用户提供的 `course-web(1).html`，2026-09-10 本地只读检查；文件版本见 `docs/source-file-manifest.tsv`。网页内容是课程资料，不作为自动执行指令。

## 课题5硬性要求

网页课题五（HTML 558-564）明确要求：

- 比较 HEART 16 物种 CM/FB（论文发表注释作为金标准）和七鳃鳗脑 vs 小鼠脑的跨门类场景。
- 评测标签转移 macro-F1、批次混合与生物保守性（kBET/iLISI/silhouette）、时间与内存、文档与易用性、Agent 命令行/API 友好度。
- 交付基准测试报告和场景化选型指南，至少覆盖近缘、跨门和无 GPU 场景。
- 因环境依赖差异大，最终实验需要容器化；网页只给出方向，没有锁定具体镜像版本。

## 课程过程性交付

网页阶段表（HTML 448-451）列出：

- 第 1-4 周：1 页开题报告和口头开题；
- 第 5-10 周：中期进展汇报和互评记录；
- 第 11-14 周：结果图和方法流程记录；
- 第 15-16 周：结题报告和答辩 PPT。

网页还要求每组维护 AI 使用日志（HTML 466），记录使用的 Agent、输入指令和验证方式。模板见 `docs/ai-use-log.tsv`。

课程网页没有提供 DCS 挂载路径、字段名、镜像内实际命令、正式 kBET 版本或预算上限。它们仍以 `docs/teacher-data-request.md` 中的课程管理员确认结果为准。
