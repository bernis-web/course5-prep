## 0. 两种启动类型

| 类型 | 目的 | 前置门槛 |
| --- | --- | --- |
| **A 核验启动** | 实例内只读探针取证（G2：工具版本/入口、GPU、正式 kBET） | 组内明确批准一次受控启动，**或**课程方提供免自建实例的安全核验方式 |
| **B 实验启动**（HEART pilot 首次单卡 smoke） | 真实数据小规模试跑 | `docs/next-round-handoff.md` §5 八项全部勾选，且 `startup_preflight.py` 返回 `ready_for_execution: true` |

两类门槛都不满足时：只做页面级复核（镜像页、软件清单、价格页），证据照常记录，不开机。

## 1. 启动前检查（逐项勾选，缺一不开机）

- [ ] 启动类型已声明（A/B），对应门槛证据在案：A 类 = 组内批准记录或课程方说明；B 类 = §5 清单全勾
- [ ] 区域一致：实例区域与项目/数据所在区域相同（DCS-华北2 / DCS-华南1，以 G1 证据为准）
- [ ] 项目与角色：本次操作在自己账号下进行；账号在共享项目中的角色**不是访客**（访客无法运行分析）
- [ ] 计费归属已确认：项目关联哪个计费组、本次费用从哪里扣（个人体验金 / 课程计费组）；已记录余额快照（金额 + 时间戳）
- [ ] 镜像已定并记录：从 `config/startup-preflight.json` 的 `page_level_image_candidates` 中选定（如 `SATURN--22`），写入当次运行记录
- [ ] 机型已定：默认 **4090×1**（¥17.4/时，22 vCPU / 90 GB）；仅单卡不足**且另行批准**后才用 4090×2（¥44.3/时）
- [ ] 停机负责人已**指名**（真实姓名记入当次运行记录）；不把预算设置当作自动停机保证
- [ ] 三项上限已复述并达成共识：**25 分钟硬停 / 峰值内存 75 GB（机型上限 90 GB，留 15 GB 余量）/ 单次 ¥10**，任一达到立即手动停机
- [ ] 本次目的无需上传/复制数据即可达成（A 类仅跑只读探针；B 类仅使用课程共享数据的既有挂载）
- [ ] 计时起点确定：以实例进入「运行中」状态的时刻为准，记入当次运行记录

> 价格与余额来源为 2026-09-09 只读审计（当时余额 ¥99）；启动前应在页面重新核对当前价格与余额，若与 `config/dcs-budget-plan.json` 不一致，先更新记录再继续。

## 2. 运行中纪律（每 5 分钟核对一轮）

| 检查项 | 达到阈值的动作 |
| --- | --- |
| 已运行时长 | ≥ 25 分钟 → 立即执行第 3 节停止清单 |
| 显存/内存（`nvidia-smi` / 系统监视） | 峰值 ≥ 75 GB → 立即停止清单 |
| 费用读数 | ≥ ¥10 → 立即停止清单 |
| 任务状态 | 完成 → **先取证，再**停止清单 |

A 类核验启动在实例内只执行既定只读命令，不做任何环境变更：

```powershell
python scripts/dcs_readonly_probe.py --output <运行目录>/dcs-readonly-probe.json
```

- 不安装包、不升级、不改配置；实例内环境与镜像页面声明不符时，只记录差异并停机（`BENGAL--SAMap--17` 的 samap `1.0.1`/`1.0.16` 双版本歧义在实例内**以记录消解**，不通过安装消除）。

## 3. 停止清单（先取证 → 后停机 → 再记账）

- [ ] 证据已保存：探针/产物 JSON 落到运行目录（不是只在实例里）
- [ ] 实例已停止：在页面确认状态为已停止/已释放（关闭浏览器标签不算停机）
- [ ] 实际费用已记录，并与预估对比（参考：4090×1 满 25 分钟 ≈ ¥7.25，低于 ¥10 上限）
- [ ] A 类取证回填：本地 `python scripts/environment_contract.py <报告.json> --profile SATURN--22` 对齐检查；证据回填 `config/startup-preflight.json`（`image_recommendation` / `image_versions` / `kbet_implementation` / `kbet_version` / `readonly_sample_command`）；证据摘要追加 `docs/dcs-readonly-audit.md`
- [ ] 当次运行记录已完整（见第 5 节模板）
- [ ] 未把账号标识、凭据、cookie、私有路径原文写入仓库或日志

## 4. 红线

出现 `docs/next-round-handoff.md` §4 所列任一情形（登录/验证码、邀请/权限变更、创建实例/任务、付费、实例内装包、超预算、字段或物种选择影响实验设计、敏感信息入库）→ 立即停止当前动作并向用户报告，不得自行继续。
