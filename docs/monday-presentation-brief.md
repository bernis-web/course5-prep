## 3. 文献精读口播稿（60-90 秒/篇）

### 3.1 HEART 论文

论文：*Spatially resolved single-cell atlas reveals the macroevolutionary trajectory of animal hearts*，DOI `10.1126/science.adw0855`。

> 这篇论文构建了动物心脏的跨物种单细胞图谱，覆盖 27 个物种；其中 16 个物种、约 48 万个细胞做了整合分析。作者用 SATURN 把不同物种的细胞放到同一个空间里比较，用 SAMap 找跨物种对应的细胞类型。方法上有三个关键设置：用蛋白质序列嵌入（ESM2B）捕捉基因难以跨物种比较的问题，用 2000 个宏基因和 8000 个高变基因控制计算量。对我们的意义：它是我们的数据来源，也提供了细胞类型标签当"标准答案"。但要注意：论文的结果是作者用他们的方式跑出来的，我们的任务是公平评测，必须自己统一跑一遍才算数。数据编号是 CNGB `CNP0006537`——这只是检索线索，不等于平台里的数据路径。

精读时要能回答：

1. 为什么选 HEART 当主数据：物种跨度大、有现成的细胞类型标签、可以先切一小块跑通；
2. 为什么不能直接抄论文结果：我们比较的是工具，输入、规则、评分必须统一；
3. 为什么先只跑 2-3 个物种：先证明整个流程能走完，再谈扩大规模。

### 3.2 LBSPA 论文

论文：*Lamprey 3D single-cell transcriptomics reveals ancestral and specialized features of the vertebrate brain*，DOI `10.1126/science.aea2535`。

> 这篇论文构建了七鳃鳗全脑图谱，同时有空间数据和单核数据两部分。我们只关注单核部分：约 4.2 万个高质量细胞核、209 种细胞簇。论文做过七鳃鳗-小鼠的比较，用了约 6900 个一对一同源基因和 scVI。七鳃鳗是无颌类，代表非常远的物种距离。对我们的意义：单细胞实验做完后，用它做"换个物种跨度再试一次"的补充验证——如果结论在更远的物种、更稀疏的基因对应关系下依然成立，结论就更可靠。空间数据暂不进主实验：数据模态不同，混在一起说不清是谁的影响。

精读时要能回答：

1. 为什么 LBSPA 后置：物种非常远 + 数据是单核不是单细胞，一次改两个变量说不清原因；
2. 为什么保留它：它是检验结论稳健性的最好补充场景；
3. 为什么强调一对一同源基因：不同工具处理基因对应关系的方式不同，必须统一。

## 4. 外组同学接手操作卡（完整命令）

前提：装好 Python 和 Git，有仓库访问权限。逐条复制运行即可，每条命令前面是它要做的事。

```powershell
# 1. 拿到代码
git clone https://github.com/bernis-web/course5-prep.git
Set-Location course5-prep

# 2. 安装依赖
python -m pip install -r requirements.txt

# 3. 跑自动测试，确认环境正常（应显示 47 个测试全部通过）
python -m unittest discover -s tests -v

# 4. 跑一遍示例流程，熟悉输出长什么样（用合成数据，不碰真实数据）
python scripts/smoke_test.py --outdir smoke-output

# 5. 检查实验计划是否自洽
python scripts/plan_contract.py

# 6. 核算一次试跑的费用（4090 单卡方案）
python scripts/budget_check.py --profile 4090x1

# 7. 查看当前还差哪些证据才能正式开跑（差项会列出来，属于正常状态）
python scripts/startup_preflight.py
```

第 7 步列出的差项就是当前待办：数据路径、字段、软件版本需要拿到课程数据入口后在平台上核对；这些核对都不花钱。完整核对清单见 `docs/minimal-verification-runbook.md`。
