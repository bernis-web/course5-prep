## 二、填写表单

### 2.1 基本信息

| 字段 | 填入内容 |
|---|---|
| **镜像名称**（必填） | `g5-opca-container` |
| **镜像描述** | `课题5 oPCA 基线可复现容器：python3.9 + numpy1.23.5 / scipy1.10.1 / pandas1.5.3 / sklearn1.6.1 / anndata0.10.8 / scanpy1.9.3 / h5py3.8.0，无 GPU` |
| 镜像标签 | 可留空（或填 `course5`） |

### 2.2 镜像来源

- **「基于平台镜像」保持选中**（默认就是选中状态，不要动）
- 点 **选择镜像** 按钮
- 在弹出的列表里选 **`SATURN--22`**（创建者 zhongliyuan）
- 确认后，「镜像地址」会自动带出：
  `public-library/zhongliyuan_57362367597d49499e5bc388096a17f1_public:latest`

### 2.3 工具包及版本 ← 关键一步

在 **Python3** 那一组的 **添加** 按钮上点一下，会新增一行输入框。
把下面 **7 行逐条填入**（一行一个包，格式就是 `包名==版本`）：

```
numpy==1.23.5
scipy==1.10.1
pandas==1.5.3
scikit-learn==1.6.1
anndata==0.10.8
scanpy==1.9.3
h5py==3.8.0
```

> **为什么还是全填**：SATURN--22 里已经有 4 个包版本相同（numpy / anndata / scanpy / sklearn），
> 但显式写全能让镜像自带一份「本项目要用的确切版本」，避免以后基础镜像变动导致漂移。
>
> **如果「添加」只能加一行**：改成一条 `&&` 连起来的 Bash 指令形式，或者
> 点「Bash指令」标签页，把这行贴进去：
> ```
> pip install numpy==1.23.5 scipy==1.10.1 pandas==1.5.3 scikit-learn==1.6.1 anndata==0.10.8 scanpy==1.9.3 h5py==3.8.0
> ```

### 2.4 R 组

**留空**，不要添加任何 R 包。本项目不用 R。
