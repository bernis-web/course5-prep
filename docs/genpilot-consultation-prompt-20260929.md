## 项目背景

我们正在完成“跨物种心脏单细胞数据整合与评测”课题。当前三物种 pilot 为 `Homo_sapiens`、`Mus_musculus`、`Danio_rerio`，主要细胞类型为 `CM` 和 `FB`。空间组学不进入主评测；单核数据只在单细胞主结论稳定后做小规模补充。

候选方法为 SATURN、SAMap 和 ortholog-PCA；scVI 仅作为后续可选消融，不自动进入主榜。

现有 SATURN v71/v72 使用同一批 4,606 个细胞训练和评估，目标物种标签参与过训练，因此只能称为 `transductive/in-sample exploratory evaluation`。候选 v97g 人到鼠 coarse accuracy 为 61.79%，majority 为 48.17%，但 provenance 和逐细胞产物仍需恢复。旧 SAMap 结果存在条码未加物种前缀、`truth NA=3`、fine/exact 逐细胞结果缺失，已冻结为 `legacy_noncompliant_20260928`，不能进正式主榜。

拟采用三个协议家族，并细分为可审计标签：

1. `TLB` 主榜：所有物种表达可参与联合整合，但目标物种标签不得进入训练、调参、邻域构造或阈值选择，只能在最终评分时读取。
2. `SH-T` / `SH-I`：按 donor/sample/解剖区域/批次留出；若 query 表达参与联合拟合，标为 SH-T；只有冻结模型直接 transform 且 query 表达不参与拟合时标为 SH-I。
3. `OOS-S`：完全未见物种的表达和标签均不参与训练；只有方法存在冻结模型的 unseen-species transform 时才能报告，否则填 `N/A`。
