### 第 7 页：首批基线结果（核心）

> 这是今天的核心成果。scVI 是深度学习方法，把每个细胞两万多个基因的表达压缩成 10 维的向量，再用向量去预测细胞类型。三个物种用完全一样的协议：一样的预处理、一样的训练轮数、一样的随机种子、一样的评估方式。

## 3. 可能被问到的问题（备答）

**Q：98% 是不是太高了，是不是数据泄漏？**
A：这是"细胞类型注释预测"任务——输入是细胞的表达谱，预测它属于哪类细胞，细胞类型之间表达谱差异本身就很大（心肌细胞和免疫细胞完全不同），所以高准确率是合理的。我们做了 80/20 的留出集划分、按类型分层抽样、固定随机种子；同协议也会重复 3 个种子取平均。另外三个工具用同一套划分，比较的是相对表现。

**Q：斑马鱼为什么低这么多？**
A：两个可能原因：一是数据里红细胞占比超过 20%（斑马鱼数据的特点），红细胞和其他细胞的表达谱差异极大但内部又很均一；二是斑马鱼与哺乳类演化距离较远。这正是跨物种评测要量化的"物种跨度影响"。

**Q：花了多少钱？**
A：目前所有计算都走平台的 1 核 4G 小规格，单次几毛钱；正式训练会上 GPU，单次限费限时（保险丝已设），费用记课程方账户。个人账户分文未动。

**Q：为什么用离线任务而不是网页界面？**
A：平台的交互界面需要华大内网权限（官方工单确认），而离线任务接口是公网可用的。我们把提交流程自动化后，反而比手动操作更稳定、可复现——每次运行的脚本和参数都存档了。

**Q：SAMap 的"垫片"是什么，会不会影响结果？**
A：SAMap 依赖一个 C++ 加速库，容器的编译器太老编不过。我们用 Python 精确近邻搜索替代它的近似搜索——**结果只会更准**（没有近似误差），只是大五万细胞时会慢一些。这个替换已作为方法变更正式记录，报告里会注明。
